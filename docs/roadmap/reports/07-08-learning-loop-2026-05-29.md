# 07.08 Learning Loop

Plan 07.08 is complete. FlowForce now has tenant-scoped AI learning feedback that records accepted and rejected recommendations without mixing learning signals across tenants.

## Completed

- Added `buildAILearningSignal(input)` and `summarizeAILearningSignals(signals)` for product-side learning contracts.
- Added `ai_recommendation_feedback` as the tenant-only feedback ledger.
- Added `record_ai_recommendation_feedback(source_table, source_id, outcome, reason_code, notes)` for manager feedback capture.
- Added `get_ai_learning_adjustment(company_id, prompt_key, suggestion_type)` for bounded future ranking hints.
- Added summary/readiness views that enforce `feedback_scope = 'tenant'` and `no_cross_tenant_training = true`.
- Added audit event coverage for recorded learning feedback.

## Safety Position

The learning loop stores source metadata, outcome, reason code, and optional short notes. It does not store raw AI context for model training, it does not train globally, and it does not let one tenant's feedback affect another tenant.

Feedback can only be recorded against reviewed suggestions from the scheduling, inventory/waste, and compliance/workflow assistant ledgers. Accepted feedback requires an approved suggestion; rejected feedback requires a rejected suggestion.
