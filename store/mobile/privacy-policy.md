# FlowForce Mobile Privacy Policy Draft

Date: 2026-05-30

This draft exists so app-store readiness work has a concrete privacy and permission baseline. Legal review is still required before production submission.

## Data We Process

FlowForce processes company, user, schedule, task, message, form, checklist, inventory, purchasing, waste, approval, audit, and notification data needed to run workplace operations.

## Mobile Permissions

- Push notifications: used for urgent operational work such as assigned tasks, schedule changes, approvals, messages, low stock, and overdue workflows.
- Camera: used only when a user scans a code or attaches photo/video evidence to a task, form, inventory count, or workflow.
- Microphone: used only when a user records audio evidence inside a form or workflow.
- Photos/media: used only when a user selects existing media as workflow evidence.

## Offline Data

The mobile app may temporarily store queued task, form, and inventory count mutations on the device while offline. Evidence-like file and blob payloads are stored as metadata until sync can safely replay the workflow.

## Data Control

Company administrators can request data export, deletion, and support review through FlowForce support channels. Tenant data remains scoped by company membership and role permissions.
